# Open-Box 真机验收指南(P7)

> 这份文档给**第一次在真实 OpenWrt 上跑 Open-Box** 的人用。
> 请**按顺序**做,每步都写了"应该看到什么"。任何一步对不上,**先停下**,把命令和实际输出贴回来再继续——继续下去可能让路由器断网。

**当前状态:v0.1.0 的所有代码从未在真实硬件上运行过。** 这次测试的目的就是找出问题。预期会有需要修的地方,这是正常的。

## 开始之前

**准备一条退路。** 本项目会接管路由器的流量与 DNS。请确保你能在出问题时恢复:

- 知道怎么进路由器的 **LuCI 网页**(通常 `http://192.168.1.1`)
- 知道怎么 **SSH** 进路由器(`ssh root@192.168.1.1`)
- 最好用**不是当前唯一上网出口**的那台路由器来测;若只有一台,先确认你会用手机热点应急
- 若路由器支持,**先备份配置**:LuCI → 系统 → 备份/升级 → 生成备份存档

**设备要求:** x86_64 或 aarch64 架构、可用存储 ≥512MB、内存 ≥512MB、OpenWrt 21.02 以上。

---

## 第 1 步:确认设备符合要求

SSH 进路由器,执行:

```sh
uname -m; grep -E 'DISTRIB_(ID|RELEASE)' /etc/openwrt_release; free | head -2; df -h /
```

**应该看到:** 架构是 `x86_64` 或 `aarch64`;OpenWrt 版本 ≥21.02;内存与根分区剩余空间满足上面的要求。

若架构是 `mips`、`arm`(32 位)等,**到此为止**——本项目不支持,安装脚本也会拒绝。

---

## 第 2 步:最关键的一次预检(强烈建议先做)

整个方案的成败首先取决于**捆绑的 Node 运行时能否在你的固件上启动**。先单独验证这一条,再谈安装:

```sh
cd /tmp
wget -O ob.tar.gz https://github.com/liandu2024/Open-Box/releases/latest/download/open-box-linux-$(uname -m | sed 's/x86_64/x64/;s/aarch64/arm64/').tar.gz
mkdir -p obtest && tar -xzf ob.tar.gz -C obtest
LD_LIBRARY_PATH=/tmp/obtest/node/lib /tmp/obtest/node/bin/node -v
```

**应该看到:** `v24.18.0`

**如果报错**(例如 `Error loading shared library ...` 或 `not found`),**请立刻停下并把完整报错贴回来**。这说明 musl 库捆绑还差东西,继续安装也没有意义。这是本次测试最重要的一个信息点。

顺便验证内核:

```sh
/tmp/obtest/bin/sing-box version
```

**应该看到:** `sing-box version 1.13.14` 及环境信息。

清理:`rm -rf /tmp/obtest /tmp/ob.tar.gz`

---

## 第 3 步:安装

二选一(网络能直连 GitHub 就用第一条,否则用加速版):

**直连:**
```sh
wget -O- https://raw.githubusercontent.com/liandu2024/Open-Box/main/scripts/install.sh | sh
```

**加速(把 `<镜像前缀>` 换成你可用的 GitHub 加速站,例如 `https://ghfast.top`):**
```sh
wget -O- https://raw.githubusercontent.com/liandu2024/Open-Box/main/scripts/install.sh | sh -s -- --mirror <镜像前缀>
```

**应该看到:** 预检逐项通过 → 下载 → 校验通过 → 铺装 → 最后打印面板地址 `http://<你的路由器IP>:2026`,并提示首次打开需要设置密码。

**此时内核不会启动**(你还没配置任何节点),这是预期行为。

**若安装中途失败:** 把输出贴回来。脚本设计成失败时不留半成品,但请顺手确认 `ls /opt/open-box` 的情况。

---

## 第 4 步:打开面板

浏览器访问 `http://<路由器IP>:2026`

**应该看到:** 强制设置密码的界面(不是登录框,是"设置密码")。设一个 **8 位以上**的密码。

设完后会进入首次引导向导。

**若打不开:** 依次检查
```sh
/etc/init.d/openbox-panel status
logread | grep -i openbox | tail -20
```
把输出贴回来。

---

## 第 5 步:跟着向导走一遍

向导会依次问:界面语言 → 你所在的国家/地区 → 确认推荐的分流方案 → 导入订阅。

导入订阅时,粘贴你的机场订阅链接(Clash 格式、sing-box 格式、或 `vless://` 这类分享链接都支持)。

**应该看到:** 解析出节点列表,并显示重命名后的效果(例如 `美国-01`、`香港-专线-01`),以及自动生成的区域策略组。

**请留意并反馈:**
- 有没有节点被跳过?跳过了哪些、什么协议?
- 重命名结果是否合理?有没有把地区认错的(比如把 `Russia` 认成美国)?

---

## 第 6 步:部署(这一步会真正接管流量)

在面板里点击部署。

**应该看到:** 部署成功,内核开始运行。此时路由器上的设备应当已经走代理。

**验证代理生效:**
```sh
curl -s https://www.gstatic.com/generate_204 -o /dev/null -w '%{http_code}\n'
```
应该返回 `204`。

**若部署失败:** 面板会告诉你失败在哪一步、哪个节点有问题。把面板上的提示和下面的输出一起贴回来:
```sh
logread | grep -i sing-box | tail -30
```

**关键:部署失败时你的网络应该仍然可用**(项目设计成失败自动恢复直连)。若部署失败后**断网了**,这是严重问题,请立刻按"应急恢复"操作并告诉我。

---

## 第 7 步:重点验证项(终审专门要求的几条)

这几条是代码评审中发现过问题的地方,请务必测:

### 7.1 部署后接管状态是否还在

若你在设置里选的是 **dnsmasq 模式**:
```sh
uci get dhcp.@dnsmasq[0].server
```
**应该看到:** 包含 `127.0.0.1#7853`。若是空的,说明重启把接管撤掉了,请告诉我。

### 7.2 紧急停止后能否恢复上网

LuCI → 服务 → Open-Box → 点「紧急停止 / 恢复直连」。

然后在路由器上:
```sh
nslookup www.baidu.com
```
**应该看到:** 能正常解析。若解析失败,说明停止清理有问题,这是严重问题。

同时确认此时**面板仍然能打开**(`http://<路由器IP>:2026`)——恢复通道不应该被自己拆掉。

### 7.3 LuCI 页面状态显示是否正确

LuCI → 服务 → Open-Box

**应该看到:** 两个服务的运行状态与实际一致(内核停了就显示"已停止",面板在跑就显示"运行中"),自启开关状态正确,按钮点了有反应。

### 7.4 重启路由器后是否自动恢复

```sh
reboot
```
等路由器起来后:
```sh
/etc/init.d/openbox status; /etc/init.d/openbox-panel status
```
**应该看到:** 两个服务都在运行,代理继续生效,面板能打开。

---

## 第 8 步:升级与卸载

**升级**(现在只有一个版本,主要是验证流程不炸):
```sh
wget -O- https://raw.githubusercontent.com/liandu2024/Open-Box/main/scripts/update.sh | sh
```
**应该看到:** 提示已是最新版本。你的订阅、密码、配置**不应该丢失**。

**卸载**(测完再做):
```sh
wget -O- https://raw.githubusercontent.com/liandu2024/Open-Box/main/scripts/uninstall.sh | sh
```
**应该看到:** 服务停止、文件清除、询问是否保留数据。

**卸载后必须确认路由器网络完全正常:**
```sh
nslookup www.baidu.com && curl -sI https://www.baidu.com | head -1
uci show firewall | grep -i openbox   # 应该没有任何输出
```

---

## 应急恢复(任何时候网络出问题都可以用)

SSH 进路由器(若 SSH 也进不去,用路由器的 failsafe 模式):

```sh
/etc/init.d/openbox stop          # 停内核并自动恢复 DNS 与防火墙
/etc/init.d/dnsmasq restart
```

若还不行,彻底卸载:
```sh
sh /opt/open-box/../uninstall.sh 2>/dev/null || wget -O- https://raw.githubusercontent.com/liandu2024/Open-Box/main/scripts/uninstall.sh | sh
```

最坏情况:LuCI → 系统 → 备份/升级 → 恢复你在开始前做的备份存档。

## 反馈时请附上

遇到问题时,这几样能极大加快定位:

```sh
# 系统信息
uname -m; cat /etc/openwrt_release
# 服务状态
/etc/init.d/openbox status; /etc/init.d/openbox-panel status
# 日志(最有用)
logread | grep -iE 'openbox|sing-box' | tail -50
# 安装目录
ls -la /opt/open-box; cat /opt/open-box/meta.json
```

以及:你在哪一步、屏幕上看到什么、期望看到什么。
