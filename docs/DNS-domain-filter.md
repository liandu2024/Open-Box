# DNS 设置与域名过滤

DNS 劫持、FakeIP 试验开关、DNS 重写收进「设置 → DNS 设置」。新增域名过滤及查询记录。

- 总开关默认关闭;预置 `https://anti-ad.net/easylist.txt`。只有首次开启应用或主动点击更新才下载,不在关闭状态后台下载。
- 名单支持增删改、停用,显示有效条数、跳过数量、最后更新时间和下载错误。开启后每天检查更新;失败保留旧名单,第一次下载失败则在改动运行配置之前返回错误。
- 域名、Hosts、Adblock 域名后缀/通配符/正则、例外规则、`important`、`dnstype` 与 `denyallow` 转成 sing-box 二进制规则集。未知修饰符和页面元素规则明确计入跳过数量。正则由内核 RE2 编译,不在 Node 请求循环里执行。
- 放行域名支持精确域名和 `*.example.com`,后者不包含根域名。用户放行最高优先级,名单例外跨名单生效。
- 修改先保存,点击「应用 DNS 设置」后通过既有部署队列生成配置和重启内核。「更新并应用」更新名单并应用全部已保存 DNS 设置。

## DNS 链路

原有 DNS 重写、本地主机名规则 → 域名过滤 → 原有终端/站点集 DNS 分流 → 原解析器。

过滤直接由 sing-box 执行,命中返回 NXDOMAIN。没有增加 DNS 转发进程,原来的代理 DNS 仍使用 TCP,来源 IP 条件、FakeIP、IPv6 设置保留。过滤关闭时不生成过滤规则。

dnsmasq 模式开启过滤时转发计划变为 `all`,关闭并应用后恢复原来的 `none / domains / all` 推算。DNS 禁用模式不接管终端 DNS,过滤只适用于显式发给内核 7853 端口的查询。此功能按查询域名过滤,不实现浏览器页面元素过滤或对上游 CNAME 应答的逐跳审查。

## 记录与统计

通过 Clash API `/logs?level=debug` 订阅内核 DNS 事件。sing-box 1.14 的 observable 日志流独立于日志文件等级,因此文件日志继续保持 `warn`,不会把所有调试日志写到路由器闪存。

- 只计 `dns: exchange` 请求,避免每个 A/AAAA 回答条目都重复计数。过滤命中按实际内核规则索引归属到名单。
- 耗时来自内核上下文计时;不能可靠关联的并发结果不填耗时,断流/未完成记录标成「未观测到结果」。等待内核时界面标明统计可能不完整。
- 最近 24 小时、最多 20,000 条查询明细;独立小时聚合保存统计。两秒批量写入数据库,队列与待关联上下文有上限。排行榜独立聚合并限制总行数。
- 概览显示最近 24 个小时段的查询量、拦截量及占比、被拦截域名排行、平均解析耗时,位于每日流量上方;总开关关闭时隐藏。
- 终端和 dnsmasq 自己的缓存命中、旁路以及未进入内核的加密 DNS 不在观测范围。dnsmasq 转发查询标为路由器转发,不冒充真实终端。

## 数据与接口

档案 `dns.filter` 保存启用状态、名单和放行域名;名单缓存与不可变规则集在 `data/dns-filter/`;运行产物和下载状态存入 `openbox/dns-filter-runtime`、`openbox/dns-filter-lists`。更新通过新文件和新配置切换,失败不覆盖正在使用的规则集。成功应用后清理不再使用的缓存文件。

API 均继承面板登录鉴权:

- `GET /api/openbox/dns-filter`:设置、名单状态、应用状态、采集连接状态。
- `PUT /api/openbox/dns-filter`:保存设置。
- `POST /api/openbox/dns-filter/apply`:`{update: true}` 表示先更新名单。
- `GET /api/openbox/dns-filter/summary`:小时统计和排行。
- `GET /api/openbox/dns-filter/records?search=&result=&page=1&pageSize=20`:域名解析查询,支持域名搜索、结果过滤;默认每页 20 条,可选 50 / 100 条或自定义 1–1000 条。界面使用全局分页控件,接口返回校正后的页码和每页条数。

## 本次验证

本机原生 sing-box 1.14 隔离实例验证:域名边界、通配符、例外、指定查询类型、正则及 denyallow、A/AAAA、重写优先级与真实日志归属。没有使用虚构流量生成统计。

开发路由器 `192.168.3.35` 使用 `1.14.0-openbox-tcp1`:预置名单实测 91,955 条,本次下载没有不支持条目。7853 与 LAN DNS 的少量查询确认广告域名 A/AAAA 被拦截,百度解析正常,两个 Google CNAME 重写正常;DNS 代理解析器仍为 TCP。未在正式路由器部署,未进行压力测试。
