# 彩色地球图标

来自 [Twemoji](https://github.com/jdecked/twemoji) v15(`@twemoji/svg`)的四个地球:
U+1F30D 🌍 / U+1F30E 🌎 / U+1F30F 🌏 / U+1F310 🌐,图形部分 CC-BY 4.0
(版权 © Twitter, Inc and other contributors)。

用途:节点组的图标。跨地区的组(「所有-自动」「回国」)配哪面国旗都不对,给它们
一个地球。界面上另有四个单色地球(heroicons),那套是线条风格,和这四个彩色的并列
供选。

emoji 字体走不通:面板里带的两份 emoji 字体都是**只含国旗**的裁剪版
(TwemojiMozilla-flags.woff2 / NotoColorEmoji-flagsonly.ttf),🌍 落到系统字体上,
不同平台画出来的东西差别很大。直接放 SVG 才能保证三个平台看到的是同一个图标。
